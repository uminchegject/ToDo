これまでに身につけたスキル
================================================================================
【要約】
エンジニア・TAとしての開発経験と、コンピュテーショナルデザインの研究経験を通じて、
プログラミング・ツール開発・幾何学的な課題解決のスキルを身につけた。

【詳細】
■技術
・C++ / Python / C# 
・Unreal Engine
・Houdini / VEX
・Grasshopper
・USD / Pipeline

■設計・問題解決
・アルゴリズムを用いた形状生成
・Geometry Processing
・プロシージャルな処理の設計
・複雑な課題の細分化・整理
・ツール・ワークフローへの落とし込み

■実務
・ゲームエンジニアとしての開発経験
・TAとしてのツール開発・R&D
・技術検証
・ドキュメント化・ナレッジ共有


================================================================================
希望職種で求められるスキルと共通するもの
================================================================================
【要約】
コンピュテーショナルデザインやTAで求められる、
「技術を使って設計・制作工程を改善する力」と共通している。

【詳細】
・Grasshopperを用いたパラメトリックデザイン
・Python / C#等によるツール開発
・アルゴリズムによる設計支援
・複雑な形状・幾何学的課題の解決
・設計・制作工程の自動化
・CAD / BIMツールとの連携
・R&D・技術検証
・技術をワークフローとして整理する力

↓

ゲームTAで培った
「技術 × 制作工程の効率化」
を建築・デザイン分野へ展開できる。


================================================================================
希望職種に必要とされるスキルで不足しているもの
================================================================================
【要約】
建築・設計分野の実務経験と、BIMを中心とした設計ツールの実践経験が不足している。

【詳細】
・建築設計の実務知識
・Revit / BIMの実務経験
・建築業界特有の設計・施工プロセス
・建築法規・構造等の周辺知識
・実案件におけるGrasshopperの活用経験
・設計者との協働経験


================================================================================
不足しているスキルをどう補うか
================================================================================
【要約】
実務を通じて建築分野の知識を身につけながら、
既に持っているプログラミング・Houdini等の技術と組み合わせて習得する。

【詳細】
・Grasshopperを実案件を想定して継続的に学習
・Revit / BIMの基礎～実務スキルを習得
・建築設計・施工プロセスを理解する
・建築分野の事例・技術記事・論文を調査する
・R&Dとして実際の設計課題を題材に技術検証する
・Python / C#等を活用して設計支援ツールを試作する
・実務で得た知識をドキュメント化・共有する
