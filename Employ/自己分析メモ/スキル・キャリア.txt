================================================================================

プログラミング・ツール開発・幾何学的な課題解決のスキルを身につけた。

【詳細】
■技術
・C++ / Python / C# 
・Unreal Engine
・Houdini / VEX
・Grasshopper
・USD / Pipeline

■設計・問題解決
・アルゴリズムを用いた形状生成
・Geometry Processing
・プロシージャルな処理の設計
・複雑な課題の細分化・整理
・ツール・ワークフローへの落とし込み

■実務
・ゲームエンジニアとしての開発経験
・TAとしてのツール開発・R&D
・技術検証
・ドキュメント化・ナレッジ共有


================================================================================
希望職種で求められるスキルと共通するもの
================================================================================
【要約】
コンピュテーショナルデザインやTAで求められる、「技術を使って設計・制作工程を改善する力」と共通している。
ゲームTAで培った「技術 × 制作工程の効率化」を建築・デザイン分野へ展開できる。

【詳細】
・Grasshopperを用いたパラメトリックデザイン
・Python / C#等によるツール開発
・アルゴリズムによる設計支援
・複雑な形状・幾何学的課題の解決
・設計・制作工程の自動化
・CAD / BIMツールとの連携
・R&D・技術検証
・技術をワークフローとして整理する力


================================================================================
不足しているスキル
================================================================================
【要約】
建築・設計分野の実務経験やRevit / BIMなどの設計ツールの実践経験が不足しているため、
実務やR&Dを通じて建築分野の知識・経験を身につけ、既に持っているプログラミング・Houdini・Grasshopper等の技術と組み合わせて補っていく。

【詳細】
・建築設計・施工プロセスや建築法規・構造等の基礎知識を習得する
・Revit / BIMの基礎から実務レベルまで継続的に学習する
・実案件を想定した課題に取り組み、Grasshopperの実践的な活用方法を身につける
・建築分野の事例・技術記事・論文を調査し、設計・施工への理解を深める
・R&Dとして実際の設計課題を題材に技術検証を行う
・Python / C#等を活用し、設計者の業務を支援するツールを試作する
・実務を通じて設計者との協働経験を積み、得られた知識や技術をドキュメント化・共有する
