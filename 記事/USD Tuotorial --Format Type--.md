# USD Tuotorial --Format Type--

## フォーマット形式
USDには複数の保存形式が存在し、それぞれに特徴があります。
その中でも代表的な下記3つのフォーマットについて説明します。

### USDA
USDA（USD ASCII）は、USDデータをテキスト形式で保存するフォーマットです。
ファイルの内容をテキストエディタで直接確認できるため、学習やデバッグに適しています。
また、Gitなどのバージョン管理システムで差分を確認しやすいという利点もあります。
一方で、テキスト形式であるためファイルサイズが大きくなりやすく、読み込み速度も比較的遅くなります。

### USDC
USDC（USD Crate）は、USDデータをバイナリ形式で保存するフォーマットです。
人が直接内容を読むことはできませんが、ファイルサイズが小さく、読み込み速度が高速であるという特徴があります。
大規模なシーンデータを扱う際のパフォーマンスに優れているため、実際の制作現場やゲーム、映像制作などではUSDCが利用されることが多くなっています。

### USD
USDでは、テキスト形式のUSDAとバイナリ形式のUSDCの両方を、共通の拡張子である .usd で保存できます。
そのため、ファイル名だけを見ても内部形式がUSDAなのかUSDCなのかを判断することはできません。
Referenceなどで他のUSDファイルを参照している場合でも、拡張子を変更することなく内部形式だけを切り替えられるため、
アセット管理やパイプライン運用をシンプルにできます。
そのためUSDでは、参照パスの安定性を重視する場合は .usd を使用し、必要に応じて内部形式を USDA と USDC の間で切り替えることができます。一方で、可読性を重視するレイヤーには .usda、大容量データには .usdc を明示的に使用する運用も一般的です。
