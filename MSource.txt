○東熱ビル
## 概要
東熱ビルのアルミルーバーを用いた特徴的なファサードを、プロシージャルに表現しました。
これらのルーバーは、角度や陰影の変化を伴いながら連続的に配置されており、「空気の流れ」を可視化するような表情を生み出しています。
プロシージャル表現では、このリズム性を再現するため、ファサード面に沿ってポイントを生成し、
各ポイントに回転・スケール・密度といったアトリビュートを付与したうえで、Copy to Pointsを用いてルーバーを配置しています。

## 東熱ビルとは
東熱ビルは、東京都中央区京橋に建つオフィスビルで、建築設備工事会社の新社屋として計画された建築です。
この建物は、省エネルギー性と快適な執務環境の両立を目指した「都市型中小オフィスビルの省CO₂モデル」として設計されており、
対流併用型放射空調や自然換気支援システムなど、先進的な環境制御技術が導入されています。
また外装デザインにおいては、グラデーション状に構成されたアルミルーバーが特徴で、
建築設備企業としての技術的なイメージを象徴するとともに、日射制御や熱負荷低減にも寄与する機能的なファサードとなっています。

void generate_base_point(
    vector dir; 
    vector pos; 
    float unit_size; 
    int unit_num; 
    float slide_pattern_list[]; 
    vector color_pattern_list[])
{
    vector up = {0, 1, 0};
    vector fwd = normalize(dir);
    vector tangent = normalize(cross(fwd, up));
    
    int pattern_len = len(slide_pattern_list);
    
    for (int unit_idx = 0; unit_idx < unit_num; unit_idx++)
    {
        for (int pattern_idx = 0; pattern_idx < pattern_len; pattern_idx++)
        {
            float slider = slide_pattern_list[pattern_idx];
            vector color = color_pattern_list[pattern_idx];
            
            if (slider == 0) continue;
		 
			
            vector spawn_pos = pos
                + fwd * unit_size * (unit_idx * pattern_len + pattern_idx)
                + tangent * unit_size * slider;
            
            int pt = addpoint(0, spawn_pos);
            
            setpointattrib(0, "scale", pt, set(unit_size, unit_size, unit_size * 2), "set");
            setpointattrib(0, "Cd", pt, color, "set");
            setpointattrib(0, "N", pt, tangent, "set");
        }
    }
}
