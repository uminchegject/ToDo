■カジュアルPR
これまで、ゲームエンジニア、テクニカルアーティストとして、制作現場の開発や業務効率化に取り組んできました。
新卒ではゲームエンジニアとして、UI開発やコンシューマー機への移植、バグ修正・運用対応などを経験しました。
その後、より現場全体の作業効率や制作体験を改善できる仕事に携わりたいと考え、テクニカルアーティストへ転向しました。
現在はHoudiniを中心に、ツール開発やR&D、新技術の検証などを行っています。
その中で、Houdiniを用いたプロシージャルなワークフロー開発や、ツール開発によって制作工程を改善していくことに興味を持つようになりました。
また、大学では建築を学び、GrasshopperやC#を用いた形状生成や、アルゴリズムを活用した設計検討に取り組んでいました。

これまでの経験から、技術を活用して制作・設計業務を効率化することに関心があり、ゲーム業界だけでなく建築分野でも、
これまでの経験を活かせるのではないかと考え、建築業界への転身を考えています。
今後は、GrasshopperやPython、BIMなどを学びながら、
建築設計の業務効率化や、コンピュテーショナルデザインを活用した設計・表現について経験を積んでいきたいと考えています。

今回のカジュアル面談では、実際のコンピュテーショナルデザイナーの業務内容や、
建築・設計現場の課題に対してどのように業務改善を行っているのかについてお伺いしたいです。
また、自分のこれまでのエンジニア・TAとしての経験や、Houdini・プログラミング・Grasshopperなどの経験が、
建築分野でどのように活かせるのかについてもお話を伺えればと考えています。

●Detail Volume Base Point
float base_ratio = ch("base_ratio");
float unit_size = ch("unit_size");
float unit_ratio = ch("unit_ratio");
float offset_ratio = ch("offset_ratio");
float toggle_vertical = chi("toggle_vertical");

if(toggle_vertical){
	vector base_scale = v@scale;
	base_scale.y /= 2;
	base_scale.y *= base_ratio;
	vector base_pos = v@P;

	int unit_num = int(base_scale.y / unit_size);
	for(int i = 0; i < unit_num; i++)
	{
		vector pos = v@P;
		pos.y += i * (base_scale.y / unit_num);
		
		vector scale = base_scale;
		scale.y = base_scale.y / unit_num;
		scale.y *= unit_ratio;
		scale.x *= offset_ratio;
		scale.z *= offset_ratio;
		
		int pt = addpoint(0, pos);
		setpointattrib(0, "scale", pt, scale);
	}
}
else{
	vector base_scale = v@scale;
	base_scale.x *= base_ratio;
	vector base_pos = v@P;

	int unit_num = int(base_scale.x / unit_size);
	for(int i = 0; i < unit_num; i++)
	{
		vector pos = v@P;
		pos.x -= base_scale.x / 2;
		pos.x += (i + 0.5) * (base_scale.x / unit_num);
		
		vector scale = base_scale;
		scale.x = base_scale.x / unit_num;
		scale.x *= unit_ratio;
		scale.z *= offset_ratio;
		
		int pt = addpoint(0, pos);
		setpointattrib(0, "scale", pt, scale);
	}

	base_scale = v@scale;
	base_scale.z *= base_ratio;

	unit_num = int(base_scale.z / unit_size);
	for(int i = 0; i < unit_num; i++)
	{
		vector pos = v@P;
		pos.z -= base_scale.z / 2;
		pos.z += (i + 0.5) * (base_scale.z / unit_num);
		
		vector scale = base_scale;
		scale.z = base_scale.z / unit_num;
		scale.z *= unit_ratio;
		scale.x *= offset_ratio;
		
		int pt = addpoint(0, pos);
		setpointattrib(0, "scale", pt, scale);
	}
}
